# 2026-10-20 Data and Stage A tooling, tested on a stand-in library

Built while the snips are in transit, so the lease goes on real work tomorrow.
Everything was exercised end to end on `ngx-gpu` against a stand-in library:
the 32 untuned-SDXL smoke images, each turned into a 4-frame "burst" (small
crops plus brightness changes), odd-numbered ones converted to greyscale to
mimic infrared, and all finished at 600 px JPEG quality 75. That gives 128
snips in 4 classes. The stand-in builder was a scratch script and is not kept.

## Tools (`src/`)

| Script | Does | Stand-in result |
|---|---|---|
| `common.py` | Paths; `finish_snip` (Lanczos 600, PIL default JPEG); JPEG quality estimate (order-free table match); chroma | Quality estimates exact for default/50/75/90/95; finished snip 600x600 q75 |
| `inventory.py` | Per-file size, mode, JPEG quality, SHA-256; class counts | 128 files, all 600x600 RGB q75 |
| `embed.py` | DINOv2-base CLS (unit-normalised, f16), 64-bit pHash, chroma | 128 embedded |
| `groups.py` | Near-duplicate groups: DINOv2 cosine >= tau or pHash Hamming <= 8, connected components per class; NN-similarity quantiles | tau 0.94: 5 of 32 bursts split, 0 false merges. tau 0.92: 2 split. **tau 0.90: 32 groups, exact, 0 false merges** (now the default). Recalibrate on real data by inspecting pairs near the threshold |
| `splits.py` | Whole groups to test/val/train per class with a fixed seed; test/val CSVs with SHA-256 | 0 groups straddling splits |
| `prep_stage_a.py` | Class-capped train sample; pseudo-rare subsets by whole groups; captions with day/IR from chroma; fp16-fix VAE latents at 512 (both orientations); SDXL text embeddings per caption | Correct selection (lyrebird cut to 6 from 2 groups), 7 captions, latents (66, 2, 4, 64, 64), built in 12 s. VAE batch must stay at 16 (64 x 2 ran out of memory) |
| `train_lora.py` | UNet LoRA on GPU-resident latents; n^-alpha class balancing; min-SNR weighting; cosine LR; checkpoints in diffusers LoRA format; fixed-seed sample grids | Gradients flow (LoRA B non-zero). **20.9 snips/s** at batch 32 rank 64, once latents moved to the GPU (memmap gather gave 10) |
| `generate.py` | SDXL + LoRA, finished like real snips, manifest per image (prompt, seed, LoRA SHA-256, file SHA-256) | 16 snips, 600x600 q75, manifest complete |

Chroma separates greyscale (max 0.0) from the dullest colour image (1.46).
The infrared cut-off should sit near 1, not the 4 first assumed; set it from
the real histogram.
